# 精准作业 v11：半对图标和未批改任务修改

基于 v10「实线虚线图标实时切换」，包名 `com.hailiang.workcloud.student`、版本 4.0.1.0 / 400100、权限和原修改版签名保持。精确输入、输出文件及 SHA-256 见 `build.json`。

## 半对图标

左侧题号的 HALF_WRONG 改用明确的半对勾图标。“待订正”等状态文字仍保留，半对图标不会再被这类文字分支覆盖。右侧批阅卡片的批改标记也接入原生 Compose 图标，部分正确显示同一半对勾，正确／错误保持独立标记；PENDING 不显示已批改图标。

## 修改未批改任务

首页处于“待批阅”的作业卡片新增「修改答案」，原「查看详情」保留。修改入口进入原作答页，通过原鉴权仓库读取当前作业的最新批阅详情，只开放确认没有批改结果的任务。支持原逐题作答（选择、填空、手写等）和已恢复完整内容的拍照／文件任务；外部作文应用不开放。

编辑只解除当前原生 handler 的已提交只读状态，不修改服务器成绩、参考答案、批改标记、身份或权限。后台列表仍使用真实“待批阅”状态。当前编辑会话可跨原生作答详情刷新保持，提交成功后恢复原提交流程。

重新提交继续使用原相册／笔迹、上传和原请求对象。在原 HTTP 提交执行前再读取一次最新批阅详情：账号变更、作答内容变更、批改开始／已有批改结果或作答记录 ID 变化时停止，保留当前本地编辑。实际 HTTP 原方法和原错误处理完整保留，原请求体不改写，不把服务器拒绝或网络失败当成成功；只有原请求成功返回后才消费编辑会话。

### 范围与实际限制

- 原提交接口按任务发送整份答案，因此本版仅开放**整个任务尚未批改**的情况。任务内已有任一题被批改时，该任务整体保持原只读行为，未实现混合批阅任务的逐题替换。
- 逐题作答必须已加载原设备保存的完整答案和笔迹，并与服务器已知作答对得上。缺少原作答、发现旧答案或账号不一致时不开放，防止重提时覆盖成空白。没有从解析区推造手写轨迹或补造未知答案。
- 拍照／文件任务需要原 handler 已恢复图片或原卷笔迹；外部作文仍使用原应用流程。
- 服务器是否接受已经提交任务的再次提交尚未实测。仍保留服务端最终校验；提交前读取与真正写入之间的并发状态由服务器负责。本包不能保证学校后台允许更新，也未更改后台规则。

## 离线验证

`test_revision.py` 运行实际编译 Kotlin，使用明确的 Android、数据模型和仓库替身。验证未批改任务开放、批改中／已批改拒绝、缺失或陈旧原答案、账号切换、服务器作答变化、普通提交直通、请求对象不变、原生失败传播、重试、挂起／恢复及只有原成功响应才结束编辑会话。结果见 `revision-tests.json`。

`verify.py` 检查最终签名 APK：只替换 DEX5 和 DEX11，其余载荷保持；原 HTTP 协程整体保留，并核对原 continuation 恢复到原方法，不会重复进入新检查；仅对导航、编辑会话及批改图标增加窄接入。检查跨 DEX 成员、方法编号、关键桥接寄存器、版本／权限及同证书 V2 / V3 签名。原版文件缩放、实线／虚线状态、撤销／重做和答案解析一同显隐保留。

没有连接 Pixel Tablet，没有执行 Android ART／实际界面渲染，也没有在本机调用学校服务、发送学生答案或验证真实再次提交。不能将离线 API 替身通过当作云端功能已验收。
