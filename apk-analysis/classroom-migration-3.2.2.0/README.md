# 学生端课堂 3.2.2.0：迁入 v8 累计功能

以用户提供的 `学生端课堂3.2.2.0原版.apk` 为官方基线，将干净 3.2.1.0 与当前 v8 修改版之间的功能差异迁入。保留包名 `com.hljzjx.edu.student.classroom`，版本为官方的 `3.2.2.0 / 322000`，minSdk 29、targetSdk 30。签名沿用本机 classroom-mod，与旧 v8 一致。

输入 APK、成品大小及 SHA256 见 `build.json`。最终校验见 `verification.json`。

## 保留的功能

- PPT 公共画布、等比缩放、切屏恢复测量、分屏底栏布局、画中画和离线工具栏图标。
- 自由浏览／回到老师、题目与讨论返回 PPT、讨论笔颜色、已有讨论工具和换组功能。
- AI 问问原生工具栏入口、海亮／ChatGPT 选择，以及现有本地应用入口。
- 手写题拍照／相册导入、已有照片与答案上传接入、继续作答及上传结果展示。
- 老师下发网页的“默认浏览器打开／课堂内打开”选择，完整网址保持原样。
- 资源下载、桌面入口及既有抢答开关等早期改动。

“保留”表示迁移现有实现，不代表服务器一定接受结束后的答案、同步或应用请求。续答结果继续区分请求被接受的本次快照与服务器回读，不伪造分数或新批阅。

## 新版适配

三方对比确认 77 个旧改动方法、29 个新增桥接方法和 14 个早期自有辅助类。新版与旧补丁相交的五处逐一处理：

1. 新版已删除回顾主页的 `onStop` 强制退出方法，沿用新版的删除，不复活旧方法。
2. 课堂初始化只加本地入口安装，保留新版工具栏及学生笔迹初始化。
3. 续答拦截接在新版 `submit` 之前，保留新版作答耗时计算及按作答时间降序整理提交项的流程。
4. 手写结果守卫适配新版 `loadImageIntoHandwriteView` 签名，使用新版回调寄存器，避免调用已删除的旧默认参数方法。
5. 讨论颜色钩子迁入新版方法，保留新版 Compose 源信息。

资源按名称合并，不套用旧资源表。新官方 10,341 个资源编号保留，新增 15 个 mod 资源；需要变化的旧常量按名称换算。新版课堂报告按钮可见性及两项新增文字保留。Manifest 保留新版删除旧路由过滤器的变化，同时迁入桌面入口、可调整窗口和画中画配置。

官方 DEX4 已有 65,525 个方法编号，无法直接继续扩展。将其中 91 个未修改的 Guava hash 类和 14 个自有辅助类放入 DEX13，其余原类仍在原 DEX；所有原类和方法保留。DEX1、2、3、5 沿用新版官方字节，DEX6–12 沿用 v8 字节。DEX4／13 中未列入补丁的原方法另做指令等价校验。

## 验证范围

- 成品 ZIP、无重复类、方法编号上限、原方法保留、全部补丁与辅助类的方法／字段引用。
- 官方资源编号、版本／包名、同旧 mod 的 V2／V3 签名与 zipalign。
- 本次重跑网页路由、续答结果／云端边界／照片转换、按钮避让、画中画、分屏底栏及 PPT 生命周期 JVM 替身检查。结果见 `regressions.json`。

以上为本地静态检查和实际自有 Java 加可观察框架替身测试。未连接 Pixel Tablet、未安装／卸载／清除数据，未向学校服务发送真实 HTTP／MQTT；没有真实课堂、服务器回读或浏览器分发验收结果。不能将这些检查称为平板实测通过。

## 重建

需要 `build.json` 中三份精确输入 APK，自行准备 Java 21、apktool 3.0.3、uber-apk-signer、Python 的 lxml／androguard 及已有工作区工具。将本目录放在工作区 `apk-analysis/classroom-migration-3.2.2.0/`。用于常量与指令校验的 `canonical_notice_methods.py`、`launcher_dex_linkage.py` 在归档的 `apk-analysis/` 中。

```text
python -X utf8 apk-analysis/classroom-migration-3.2.2.0/migrate.py
python -X utf8 apk-analysis/classroom-migration-3.2.2.0/verify.py
```

脚本首次从输入 APK 提取所需树；按附带的窄差异计划迁移，不需要完整原厂源码。Windows aapt2 资源构建暂存于 `%LOCALAPPDATA%/CodexBuilds/classroom-migration-322/`，避免中文路径兼容问题。签署需要使用自己的密钥；此项目的私钥不随归档分发。
