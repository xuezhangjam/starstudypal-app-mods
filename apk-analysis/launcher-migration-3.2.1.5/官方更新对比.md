# 官方 3.2.1.4 与 3.2.1.5 对比

以下是用户提供的两份官方 APK 的本地静态代码／载荷对比，不是厂商发布公告，也不代表真机行为已验证。

1. **课堂进入路径调整**：`AppRepository.openClassRoom` 的目标从课后回顾 `review.MainActivity` 改为 `RoomLiveActivity`；移除 `route=enter_class` 及相关启动标志的特殊处理。自动进课改用约 1 秒延迟回调，前台课堂检查仍约 20 秒，但调度实现变化。
2. **退出登录清理课堂任务栈**：首页和个人中心的退出登录流程新增通知课堂清理任务栈的广播，动作名 `com.hailiang.launcher.action.DISMISS_CLASSROOM_TASK`，指定学生端课堂包。
3. **后台常驻／省电策略调整**：删除旧 `ClassRoomPackageHelper`、`ClassRoomPersistentHelper` 等辅助类，多个启用入口改为直接调用 ROM 应用策略。在 ROM 初始化中把星学伴自身、学生端课堂和 `com.hailiang.stu_eye_care` 加入常驻及省电白名单；移除旧课堂结束广播分支中清除课堂常驻的处理。
4. **界面资源没有变化**：资源表及全部 `res/` 文件与 3.2.1.4 字节一致，所以不是首页、时间显示或应用排序的视觉更新。
5. **下载回调和大量 lambda 类编号变化主要来自编译重排**，所检查的课件下载方法去除编号差异后未发现新增下载功能，不能把这些编号变化说成新功能。

版本从 3.2.1.4 / 32014 升到 3.2.1.5 / 32015；包名和 min/target SDK 29 不变。变动载荷集中在 DEX1、DEX3、清单版本、构建元数据和编译 profile；DEX2、DEX4 与界面资源保持一致。哈希及清单见 `inputs.json`、`stock-payload-delta.json`，方法清单见 `vendor-changes.json`。
