# 错题本 3.3.2.0：取消拍照作业判定

用户已明确问题是在拍照时提示“未识别到作业”。本轮只处理本地相机拦截。

基于上一份“原生 MD3e、系统相机与相册”修改版继续，保留包名 `com.nice.errorbook`、版本 `3.3.2.0 / 3320`、MD3e、系统相机与相册入口，并沿用相同签名，可覆盖上一份本机修改版。

## 实际变化

- 内置相机即使没有检测到纸张/作业边框，也可以按快门；拍照忙碌时的防重复操作仍保留。
- 保存照片时使用完整照片四角，不再因为检测不到边框就删除照片。照片仍进入原预览、手动裁剪、增强与确认上传流程，原数量上限保持。
- 本地相机状态改为“自由拍照 · 可直接上传”，不再显示作业识别状态或检测框。
- 未修改题目识别、服务器判定、加入错题本、账号、网络请求或上传响应。不会把服务器返回的失败伪装成成功。

## 构建与验证

`build.py` 验证输入 SHA256 后，只修改 DEX4 的三个相机方法，新增 DEX7 的完整画面/提示辅助类，使用原有本机密钥签名。需要项目已有 Java、apktool、ECJ、D8、Android 编译 API 与签名工具；APK、第三方依赖和密钥不包含在源码包中。

`test_policy.py` 在 JVM API 模型中执行实际 Java 几何代码；`verify.py` 检查最终安装包的载荷、相机控制流、完整方法差异、引用与同签名。实际结果见 `policy-test-results.txt` 和 `verification.json`。

离线验证没有替代实机验收：没有实际唤起平板相机、拍照、裁剪或向服务器上传照片。

本目录仅包含本轮新增源码和补丁/校验脚本，不包含原软件完整源码。
