# 学生端课堂：讨论结束后换组

基于当前 `学生端课堂-3.2.2.0-v8功能迁移.apk`，处理用户 1959 截图中“已结束 · 可继续书写”时原生换组按钮消失的问题。

## 行为

- 仍附着在当前课堂、存在页面及有效当前小组，讨论状态为 **ENDED** 时，显示原生黄色 **切换小组** 按钮。
- 原生已分配组的本地选择限制仅在上述结束状态放开；讨论进行中继续原限制。只显示服务器已返回的当前讨论小组列表，沿用原选择界面和换组请求。
- 原接口确认成功后，原逻辑更新组名和组 ID、清除旧组画布、退订旧组／订阅新组并通知换组；随后恢复结束后的续写工具，保持“已结束”状态，仍可多次切换。随后原 ViewModel 刷新小组成员和笔记详情的流程保持不变。
- 原接口返回失败时，显示原失败提示，不改变当前组、组名、画布或订阅。没有把本地换个组名当作服务器换组成功。
- 历史回看、已关闭页面、无当前小组及非 ENDED 状态不被此补丁重新开放。
- 使用原控件 `tv_switch_group`；现有返回 PPT／画中画控件已有对此按钮的避让，仍沿用原全局布局处理。

保留已有续写、笔颜色、PPT、分屏、AI、图片、续答上传／结果、网页打开方式等功能。本次只改变 DEX4 中 `DiscussionFragment` 的三个方法：结束工具刷新、选择入口的结束状态分支、换组成功回调末尾的工具刷新。没有更改接口、讨论状态、原成功／失败条件、服务器返回数据或其他 DEX。

## 安装及验证

成品名称及哈希见 `build.json`；包名 `com.hljzjx.edu.student.classroom`，3.2.2.0 / 322000，min29 / target30。沿用 classroom-mod 签名，可覆盖当前同签名修改版。密钥不包含在源码归档中。

`verify.py` 检查最终签名包、唯一变动载荷、三个方法范围、其他原方法指令等价、方法／字段引用、包名／SDK／版本和证书。`test_flow.py` 执行真实最终 DEX 的守卫／工具刷新／成功与失败回调，使用可观察的 Android 视图及订阅替身，并运行旧包负对照复现按钮缺失。

这些测试没有连接 Pixel Tablet 或学校服务器，没有真实 HTTP／MQTT、安装／卸载／清除数据。**服务端是否允许在结束后变更小组，仍需实际课堂验证；接口拒绝时保留原失败提示。** 不能将替身验证称为真实云端换组验收。
