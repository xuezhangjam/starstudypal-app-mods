## 修改

- 在三星且 SDK 29 及以上启用兼容逻辑。原版提示库的 Toast 改为应用页面内短提示；已有修改版 DEX5，以及 DEX3 中登录、拍照、文件等直接 Toast 调用也接入此路径。提示使用当前前台 Activity 的页面，不需要悬浮窗权限；页面离开即移除。页面切换时只暂存最近一条提示，最长 10 秒。
- 三星上的 CommonLoginActivity 在有 savedInstanceState 的重建中不再调用 clearLocalInfo；完全初始化页面后，若已有非空本机登录凭据则回到正常首页。没有有效的本机凭据时仍停留登录页，后续首页请求仍由原服务器正常验证。
- 三星登录成功后，用 NEW_TASK / CLEAR_TASK 打开首页，结束旧的登录任务栈，避免后续崩溃恢复到已过期的登录界面。
- 首次登录页仍执行原清理；主动退出、子应用真实 401、原登录请求和服务器验证逻辑保留。没有备份、复制或回放账号凭据，没有改设备编号或系统后台权限。

保留原包名 `com.hljzjx.edu.student.launch`，版本 3.2.1.5 / 32015，原 min/target SDK、资源、权限、界面和其余修改版功能。沿用当前修改版证书，可覆盖同签名版本，无须卸载。
